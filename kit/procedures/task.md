# 执行任务（Codex，或任务说明指定的执行者）

你是**任务会话**，只做一份任务说明里的事。参数是任务编号（如 `dev-T003`）。

1. 在 `workflow/tasks/active/` 里找到编号匹配的任务说明并读完。找不到就停下来问用户。
2. 开工前运行 `git status`。工作区里有和本任务无关的改动：提醒用户（可能是并行的其他线），不要提交它们。
3. 严格按任务说明里的「只需要读」「可改范围」「不要碰」「完成标准」「验证级别」执行。
   - 需要读清单之外的文件：先确认确实有必要，只读相关小节，并在交接里说明。
   - 发现需要改「可改范围」之外的东西：停下来，在交接里写成遗留问题，不要扩大范围。
   - 长输出（编译、测试、构建日志）写进文件，只用搜索命令看错误和结论，不把全文打印进对话。
4. 做完后按 `workflow/.szy/procedures/handoff.md` 收尾。
