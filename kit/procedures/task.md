# 任务执行

任务会话只完成一个任务，不改 PLAN 或 PROGRESS。

1. 在 `workflow/tasks/active/` 找到用户指定的 `Txxx`，读完整任务文件。
2. 只读任务文件列出的 PLAN/PROGRESS 小节和源码文件；不要扫描整个项目。
3. 先看 `git status`。有无关改动时提醒用户，不覆盖或提交它们。
4. 按「可改范围」「不要碰」「完成标准」工作。需要扩大范围时先停下，把原因写入任务结果。
5. 运行任务列出的验证命令。长日志写文件，只报告结论和错误。
6. 回写任务文件：状态改为「完成」或「受阻」，填写结果、改动文件、验证、遗留问题。不要改 PLAN、PROGRESS 或其他任务。

完成后告诉用户回到新主控会话说「主控」。
